RetroPortal Extension Options

Choose how a new tab opens. The settings below are stored with chrome.storage.local and never leave your browser.

New tab mode

Good to know

  • Bundled mode does not inject scripts into the hosted site. It runs the same local React build.
  • Hosted mode is a redirect. Your browser's normal new-tab page is still overridden by this extension.
  • Preferences and notes are stored per extension install and per website; they are not synced between the two modes.
  • The extension requests only the storage permission. It never reads browsing history.
